# Agent instructions

All agent instructions for this project live in **CLAUDE.md** — one file, one
source of truth, written for every agent that works here regardless of tool.
This stub exists only because your tool auto-loads `AGENTS.md`; it will never
contain a rule, so nothing here can go stale.

Read `CLAUDE.md` in full now and treat it as your own instructions — where it
says "Claude", it means you. Its **"Other agents"** section is specifically
yours: how sessions open and close when you have no skills, which safety nets
don't run for you, and how to behave in a shared tree.
